# Force FPS

Sets Geometry Dash's target frame rate (30–1000) from the mod settings.

## Build with GitHub (no PC needed)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab → "Build Geode Mod" → **Run workflow**.
3. When it finishes, download **Build Output** and unzip it to get `ahmedtaher.force-fps.geode`.
4. Put the .geode in Geode's mods folder on your phone, then restart GD.
